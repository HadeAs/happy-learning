# 幼儿英语单词图片匹配游戏 — 设计说明

日期: 2025-01-19
状态: 设计中

---

## 1. 概述

一个面向幼儿（3-6 岁）的英语学习网页游戏。核心玩法：从单词库随机抽取 4 个单词和对应图片，上下打乱排列，玩家点击单词再点击图片进行匹配，即时反馈对错，全部完成展示庆祝效果并可再来一局。同时对家长/老师提供同页的单词库管理面板。

---

## 2. 技术选型

- **纯静态 HTML/CSS/JS**：单文件 `index.html`，无需构建工具、框架或后端
- **单词库**：`words.json` JSON 配置文件
- **图片**：已有 `img/` 目录下约 30 张 PNG 图片
- **兼容**：现代浏览器（Chrome / Safari / Edge）

---

## 3. 文件结构

```
happy_learning/
├── index.html        # 游戏主页面 + 管理面板
├── words.json        # 单词库数据
└── img/              # 图片资源
    ├── cat.png
    ├── dog.png
    └── ...           # ~30 张已有图片
```

---

## 4. 单词库 (words.json)

### 数据结构

```json
[
  { "word": "cat", "image": "img/cat.png" }
]
```

- `word`: 英文单词（显示用）
- `image`: 图片相对路径

### 种子数据

基于已有 `img/` 目录下的图片生成初始单词库：
- 文件名去掉 `.png` 即为单词，首字母大写作为显示单词
- 例如 `apple.png` → `{ "word": "Apple", "image": "img/apple.png" }`

## 6. 核心交互

### 6.1 开局

1. 从单词库随机选择 4 个不同单词
2. 单词卡片随机打乱显示顺序
3. 图片卡片独立随机打乱显示顺序

### 6.2 匹配流程

1. **点击单词卡片**：卡片高亮（橙色边框 3px + 轻微放大 scale(1.05)）
2. **点击图片卡片**：
   - **正确**：单词 + 图片卡片同时变绿（边框绿色、背景浅绿），加 ✓ 图标，锁定不可再点，播放成功音效（可选 CSS 动画）
   - **错误**：图片卡片闪红并抖动 0.4s，单词高亮取消，计入错误次数，自动恢复后可重试
3. **取消选择**：点击已选中的单词卡片可取消选择（不想选这个单词时）

### 6.3 结果展示

4 对全部正确匹配后：

- 全屏居中弹出庆祝层
- CSS 动画：撒花/星星粒子效果
- 大字："🎉 太棒了！全部正确！"
- 显示错误次数
- 按钮：**[再来一局]**

### 6.4 再来一局

- 重新随机抽取 4 个单词
- 重置所有状态（选中、配对、错误计数）

## 7. 管理面板

通过标题栏的 **[管理单词库]** 按钮展开/收起。

### 功能

- **列表**：显示所有单词，每行显示单词名 + 图片缩略图
- **添加**：输入单词名 → 选择已有图片（下拉）或上传新图片 → 确认
- **删除**：每行右侧 [删除] 按钮，需确认
- **保存**：修改自动保存到 `words.json`（通过下载触发，或本地 localStorage）

> **注意**：由于纯静态页面无法直接写文件，管理面板的变更将：
> 1. 实时更新到 `localStorage`
> 2. 提供「导出单词库」按钮，下载更新后的 `words.json` 文件

## 8. 状态管理

### 游戏状态（每局）

```
{
  selectedWords: Word[],      // 本局 4 个单词
  wordOrder: number[],        // 单词显示顺序（随机索引）
  imageOrder: number[],       // 图片显示顺序（随机索引）
  selectedWordIndex: number | null,  // 当前选中的单词索引
  matchedPairs: Set<number>,  // 已正确配对的单词索引（按原始顺序）
  errorCount: number,         // 错误次数
  gameComplete: boolean       // 本局是否完成
}
```

### 单词库状态（全局）

- 优先从 `localStorage` 读取（用户编辑后）
- 无 localStorage 时从 `words.json` 加载初始数据
- 每次管理面板修改后写回 localStorage

---

## 9. 边界情况

| 场景 | 处理方式 |
|------|----------|
| 单词库不足 4 个 | 显示提示"单词库至少需要 4 个单词"，引导去管理面板添加 |
| 选中单词后再次点同一单词 | 取消选中 |
| 已配对的卡片被再次点击 | 无响应（已锁定） |
| 单词和图片都选中后配对中 | 短暂禁用点击，等待反馈动画结束 |
| 管理面板删除所有单词 | 提示"至少需要 4 个单词才能开始游戏" |
| 图片加载失败 | 显示占位图 + 单词名 |

## 10. 非功能性

- **性能**：静态资源，零网络依赖（初始加载后）
- **可访问性**：大点击区域(≥48px)、高对比度配色
- **国际化**：仅英文单词，界面中文提示
